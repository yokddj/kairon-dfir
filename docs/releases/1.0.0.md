# Kairon DFIR 1.0.0

## Resumen

Kairon DFIR es una plataforma de investigación DFIR local-first, autoalojada y centrada en casos. Ingiere evidencia de Windows, Linux, imágenes de disco y memoria en un espacio de trabajo único, la normaliza en un modelo común buscable, y asiste al analista mediante Search, Timeline, Artifact Views, detecciones, findings y reporting — sin sustituir el juicio del analista.

## Nuevas capacidades desde la serie 0.9

### Memory Evidence Preparation

- Preparación de evidencias de memoria previa al análisis.
- Adquisición y validación de símbolos.

- Soporte de análisis de memoria Linux.
- Procesos.
- Red.
- Shell history.
- Validación ISF.

### Initial Memory Analysis

- Integración con el asistente de ingesta para lanzar el análisis inicial de memoria.

- Soporte de `linux.sockstat`.
- Normalización de resultados de red Linux.

### Shell History

- Normalización de historiales de shell.
- Backend por familia (family backend).

- Integración con Host Investigation.

- Corrección de comportamiento de `metadata_only`.
- Limpieza de tests asociados.
- Limpieza de registries.

### Hardening

- Mejoras de setup.
- Mejoras de despliegue.
- Validación de instalaciones limpias.
- Documentación específica de Linux.
- Fixtures adicionales para pruebas.

## Limitaciones conocidas

- Domain/workgroup no implementado.
- Plugin de seguridad de OpenSearch deshabilitado (`DISABLE_SECURITY_PLUGIN=true`).
- Backend/worker ejecutándose como root (sin `USER` no-root en `backend/Dockerfile` ni `user:` en los servicios `backend`/`worker` de `docker-compose.yml`).
- Límite de memoria de OpenSearch no documentado.
- Fallos de tests preexistentes ya auditados (ver sección Validación).
